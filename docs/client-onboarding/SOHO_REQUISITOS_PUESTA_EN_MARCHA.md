# Información necesaria para poner en marcha SOHO Café

Esta guía explica qué información necesitamos para configurar el punto de venta de **SOHO Café**, qué datos son indispensables para comenzar y cuáles son necesarios para controlar correctamente el inventario, los costos y la rentabilidad.

> **Importante:** podemos preparar el sistema y realizar ventas con el menú y los datos básicos del negocio. Sin embargo, si todavía no contamos con las recetas, los insumos y sus costos, el sistema no podrá mostrar existencias, costos ni márgenes confiables.

## 1. Información necesaria para preparar el sistema

### Datos del negocio

Por favor, compartir:

- [ ] Nombre comercial y razón social, si son diferentes.
- [ ] RUC vigente.
- [ ] Régimen fiscal: **Cuota Fija** o **Régimen General**.
- [ ] Indicar si los precios del menú ya incluyen IVA.
- [ ] Dirección del establecimiento.
- [ ] Número de teléfono del negocio.
- [ ] Tipo de cambio comercial utilizado para recibir dólares, si corresponde.

La información fiscal debe validarse antes de emitir comprobantes reales. Una factura emitida no debe eliminarse; cualquier reversión deberá realizarse mediante el procedimiento de anulación correspondiente.

### Datos de la persona responsable

- [ ] Nombre completo del propietario o responsable principal.
- [ ] Correo electrónico.
- [ ] Número de teléfono.
- [ ] Personal que utilizará el sistema, si ya está definido.

No es necesario registrar a todo el personal para realizar la configuración inicial. El propietario puede comenzar como usuario principal y agregar cajeros o encargados posteriormente.

## 2. Menú de productos

El menú es suficiente para preparar el catálogo inicial, siempre que cada producto incluya la siguiente información:

| Información | Ejemplo |
|---|---|
| Nombre del producto | Cappuccino |
| Precio de venta | C$ 85.00 |
| Categoría | Bebidas calientes |
| Tamaño o presentación | 12 oz / 16 oz |
| Sabores o variantes | Vainilla / Caramelo |
| Extras disponibles | Shot adicional / Leche de almendra |
| Precio de cada extra | C$ 20.00 |

### Recomendaciones para preparar el menú

- Registrar cada tamaño o presentación que tenga un precio diferente.
- Incluir productos empacados, como agua, gaseosas, galletas o café en bolsa.
- Indicar claramente qué extras aumentan el precio.
- Informar si algún producto está temporalmente fuera de venta.
- Podemos comenzar con los productos de mayor rotación y agregar el resto después.

## 3. Recetas e insumos

Para controlar correctamente el negocio necesitamos conocer **qué se utiliza para preparar cada producto**.

### Insumos

Los insumos son los materiales que SOHO compra o consume durante la operación, por ejemplo:

- café en grano;
- leche;
- azúcar;
- jarabes;
- chocolate;
- vasos y tapas;
- alimentos empacados;
- ingredientes de cocina.

Para cada insumo necesitamos:

| Información | Ejemplo |
|---|---|
| Nombre | Leche entera |
| Unidad de control | Mililitros |
| Cantidad disponible al iniciar | 20,000 ml |
| Costo de compra | C$ 45 por litro |
| Nivel mínimo deseado | 5,000 ml |
| Proveedor, si se conoce | Distribuidora Ejemplo |

### Recetas

La receta indica cuánto consume una venta de cada insumo. Por ejemplo:

> **Cappuccino de 12 oz:** 18 g de café, 120 ml de leche, 1 vaso y 1 tapa.

Para cada producto preparado necesitamos:

- [ ] Ingredientes utilizados.
- [ ] Cantidad de cada ingrediente.
- [ ] Unidad de medida: gramos, mililitros o unidades.
- [ ] Tamaño o rendimiento de la preparación.
- [ ] Pérdida o merma habitual, cuando corresponda.

Si SOHO prepara productos intermedios —por ejemplo, jarabes, salsas, cold brew o mezclas— también necesitaremos la fórmula y el rendimiento de cada preparación.

## 4. ¿Qué ocurre si comenzamos solamente con el menú?

SOHO podrá registrar ventas y emitir comprobantes una vez finalizada la instalación y las pruebas. Sin embargo, cada venta quedará registrada **sin información completa sobre lo que realmente se consumió para producirla**.

Esto tiene consecuencias importantes:

### No tendremos existencias confiables

El sistema no podrá descontar automáticamente café, leche, vasos u otros ingredientes. Por lo tanto, no podrá indicar con precisión cuánto queda disponible ni cuándo es necesario volver a comprar.

### No tendremos costos confiables

El precio de venta no indica cuánto cuesta preparar el producto. Sin las cantidades y costos de los ingredientes, el sistema no podrá calcular el costo real de un cappuccino, un postre o cualquier otro producto preparado.

### No tendremos márgenes confiables

El margen se obtiene comparando el precio de venta contra el costo real del producto. Si el costo todavía no está configurado, cualquier reporte de ganancia o rentabilidad será incompleto y podría llevar a decisiones incorrectas.

### No podremos medir correctamente las mermas

Sin una receta teórica y un inventario inicial, no podremos comparar lo que debió consumirse con lo que realmente queda. Esto dificulta detectar desperdicios, errores de preparación o diferencias de inventario.

> **Conclusión:** comenzar solamente con el menú permite abrir la caja, pero no permite administrar el inventario ni conocer con precisión la rentabilidad del negocio.

## 5. Formas de iniciar

### Opción A — Inicio rápido

SOHO entrega los datos fiscales y el menú con precios. Configuramos el catálogo, instalamos el equipo y realizamos una venta de prueba.

Esta opción permite comenzar antes, pero temporalmente:

- no habrá stock automático confiable;
- los costos aparecerán como pendientes;
- los márgenes no serán confiables;
- las alertas de reposición serán limitadas.

### Opción B — Inicio con control completo — recomendada

Además de los datos básicos y el menú, SOHO entrega:

- lista de insumos;
- inventario inicial contado;
- costos de compra;
- recetas por producto;
- subrecetas o preparaciones internas;
- unidades de medida consistentes.

Esta opción requiere más preparación, pero permite comenzar con mejor control de existencias, costos, márgenes y mermas desde el primer día.

## 6. Pruebas antes de iniciar ventas reales

Una vez recibida la información acordada, realizaremos:

- [ ] Creación del negocio y del usuario principal.
- [ ] Carga y revisión del catálogo.
- [ ] Configuración del dispositivo de venta.
- [ ] Prueba de la impresora.
- [ ] Verificación del acceso sin internet.
- [ ] Venta de prueba utilizando el flujo real.
- [ ] Revisión del comprobante y de la numeración correspondiente.
- [ ] Explicación del proceso de anulación.

La fecha definitiva de inicio se confirma después de completar correctamente estas pruebas.

## 7. Checklist para SOHO Café

### Para preparar el punto de venta

- [ ] Datos fiscales y de contacto del negocio.
- [ ] Datos del propietario o responsable.
- [ ] Menú con nombres, precios, tamaños y extras.
- [ ] Confirmación de si los precios incluyen IVA.

### Para tener inventario, costos y márgenes confiables

- [ ] Lista de insumos.
- [ ] Unidad de medida de cada insumo.
- [ ] Conteo del inventario inicial.
- [ ] Costo actual de cada insumo.
- [ ] Receta de cada producto preparado.
- [ ] Subrecetas o preparaciones internas.
- [ ] Mermas conocidas.
- [ ] Proveedores principales, si están disponibles.

En paralelo, recomendamos completar las recetas, los insumos, el inventario inicial y los costos antes de iniciar ventas reales, para que los reportes operativos y financieros sean confiables desde el primer día.
